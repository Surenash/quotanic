# Formatting

**Headers & Lists:**
- Use standard Markdown (`#`, `##`, `-`, `1.`) for structure.
- Always include a blank line before and after a list or header.

**Code Blocks:**
- Use syntax highlighting (e.g., ```python, ```tsx, ```bash).
- Provide minimal, complete, and reproducible examples where possible.

**Output Templates:**
- When suggesting a plan, use numbered steps with bold titles and bulleted details.
- When making a commit, follow conventional commit messages (e.g., `feat: add manufacturer settings`, `fix: correct pricing calculation in FBM`).

**Response Length:**
- Keep explanations concise. If a topic is complex, break it down logically.
