# Principles & Core Philosophy

**Guiding Principles:**
1. **Accuracy Over Speed in Pricing:** The FBM engine must accurately analyze CAD files and estimate costs. A slow but accurate quote is better than a fast but wrong one.
2. **User-Centric Manufacturing:** Manufacturers need clear settings and controls. The UI should prioritize ease of use for setting capabilities and pricing rates.
3. **Seamless AI Integration:** AI should assist users natively, whether in generating quotes or managing orders, without feeling like a bolted-on feature.
4. **Maintainability:** The codebase must be easily understandable by AI assistants and human developers alike.

**Priority Order:**
1. Reliability (accurate pricing, no data loss)
2. Security (safe handling of customer CAD files and data)
3. Maintainability (clean code, modular structure)
4. Performance (fast UI response, optimized background processing)
