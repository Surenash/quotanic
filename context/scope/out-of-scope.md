# Out-of-Scope

**Excluded Features:**
- **CAD Design/Editing Capabilities:** Users cannot draw or modify parts within Quotanic; they can only upload them for analysis.
- **Full ERP/MRP Replacement:** While Quotanic handles quotes and initial order management, it is not currently a full replacement for a complete Enterprise Resource Planning system (inventory tracking, deep supply chain management, etc.).
- **Consumer/B2C Market:** The platform is firmly B2B.

**Audiences:**
- Hobbyists looking for single-run 3D prints (unless explicitly supported by a specific manufacturer's settings, but not the primary focus).

**Platforms:**
- Native Mobile Applications (iOS/Android). The focus is entirely on responsive web applications.

**Deferred Items:**
- Complex multi-part assembly analysis (focusing on single-part analysis first).
