# Priorities

**Priority Stack:**
1. Fix bugs in the core FBM pricing logic (`fix_pricing_structure.py`).
2. Implement and test the UI for `manufacturer_settings_component.tsx`.
3. Improve test coverage for `test_quote_generation.py` and `test_matcher.py`.
4. Refactor large frontend components (e.g., `index.tsx`, `index.tsx.bak`) into smaller, reusable ones.

**Criteria:**
- Accuracy in quoting is always prioritized over adding a new UI feature.
- Security and stability are prioritized over speed.

**Deprioritized Items:**
- Multi-language support.
- Mobile application development.
- Support for extremely rare manufacturing processes that account for less than 1% of the market.
