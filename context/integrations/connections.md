# Integrations & Connections

**Active Integrations:**
1. **PostgreSQL:** Primary relational database for user accounts, orders, quotes, and manufacturer settings. *Note: Hosted in a Docker container on the EC2 instance due to RDS creation failures.*
2. **Redis:** Message broker for Celery asynchronous task processing (crucial for the FBM engine's `analyze_cad_file` task).
3. **AWS EC2 (ap-south-1):** Hosts the backend API (`api.quotanic.com`), Celery worker, Redis, and PostgreSQL via Docker Compose on a `t3.micro` instance.
4. **AWS Amplify:** Hosts the React frontend (`quotanic.com`) deployed directly from the repository using `amplify.yml`.
5. **AWS S3:** Used for CAD file storage (`quotanic-fbm-designs-mumbai`). Frontend uploads directly to S3 using pre-signed URLs generated by the backend API.

**Planned Integrations:**
- Email Service Provider (e.g., SendGrid or AWS SES) for quote and order notifications (likely integrated within the `notifications/` app).
- Payment Gateway (e.g., Stripe or Razorpay - noting `razorpay` is in `requirements.txt`) for processing payments on accepted quotes.

**Rejected Tools:**
- Synchronous processing of CAD files (rejected in favor of Celery/Redis due to timeout risks).
- AWS RDS (rejected temporarily due to silent creation failures).
